[heading 2] 2. Technical Architecture & Core Logic
[paragraph] A. Phase 1: Core Automation & Alignment (Expected Timeline: 3-4 Weeks + Calibration)
[paragraph, list L0] Local Data Ingestion: A lightweight interface extracts compressed audio (WAV/MP3) and absolute SMPTE timecodes locally. High-resolution 4K video files never leave local storage, eliminating bandwidth bottlenecks.
[paragraph, list L0] Semantic RAG Filtering: The system passes transcripts generated via a secure speech-to-text pipeline through a custom Retrieval-Augmented Generation (RAG) engine. It compares the dialogue against the text-based Podcast Plan to keep key narrative arcs and strip out dead air and off-topic tangents.
[paragraph, list L0] Algorithmic Camera Switching: The active speaker is determined via a local audio-amplitude and diarization script. By enforcing a 1.5-second minimum pacing hold time and a comparative loudness threshold, it mitigates microphone bleed and smoothly switches camera tracks.
[paragraph, list L0] Native FCPXML Generation with 0.5s Handles: The script outputs a native Final Cut Pro XML (FCPXML v1.8) file. When opened in Adobe Premiere Pro (v24.0+), it maps the cuts natively to the raw files with 0.5-second safety handles pre-padded onto the clip boundaries for quick pacing adjustments.
[heading 3] B. Phase 2: Micro-Moments Extraction (Expected Timeline: 2-3 Weeks)
[paragraph, list L0] Short-Form Highlight Identification: The AI infrastructure concurrently scans high-emotion text vectors and semantic peaks during the transcription phase to flag high-engagement, short-form highlights. These are programmatically compiled into a secondary sequence or dedicated project bin for rapid social media editing.
