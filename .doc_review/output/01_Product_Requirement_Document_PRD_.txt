[heading 2] 1. Product Overview & Goals
[paragraph, list L0] The objective of the Pre-Editor Engine is to eliminate the manual 2-day "rough cut" bottleneck in multi-camera video podcast production.
[paragraph, list L0] The system treats multi-cam video editing as a pure data metadata problem. Instead of processing heavy 4K video files, it extracts isolated audio tracks locally, leverages semantic AI models to filter the narrative based on a text brief, and uses deterministic audio amplitude analytics to track the active speaker.
[paragraph, list L0] The final output is a lightweight, frame-accurate FCPXML sequence importable directly into Adobe Premiere Pro with 0.5-second safety handles pre-applied.
[heading 2] 2. Technical Stack & Architecture Baseline
[paragraph, list L0] Local Processing Script: Python 3.11+
[paragraph, list L0] Audio Engineering Libraries: pydub, scipy.io.wavfile, numpy
[paragraph, list L0] Transcription API: GPT-4o transcription, ElevenLabs Scribe v2, Deepgram Nova-3
[paragraph, list L1] ElevenLabs Scribe v2: Use if Sunrise’s podcast client needs premium features like native laughter/applause tracking to automate creative camera switches.
[paragraph, list L1] Deepgram Nova-3: Use if the main goal is raw, ultra-fast speaker timestamps at the lowest possible metered API cost.
[paragraph, list L1] Alternative solution
[paragraph, list L0] LLM Engine: Gemini 3.5 Flash or Claude 3.5 Haiku (Zero-Data Retention enforced)
[paragraph, list L0] Metadata Exporter: xml.etree.ElementTree (Python native)
[paragraph, list L0] Target NLE Compatibility: Adobe Premiere Pro (v24.0+)
[heading 2] 3. Detailed Functional Modules & Engineering Specs
[heading 3] Module 1: Local Media Ingestion & Extraction (Python Worker)
[paragraph] [Raw Video Files: Cam A, Cam B, Wide] ──> FFMPEG ──> [16kHz Mono WAV Audio Tracks]
[paragraph, list L0] Input Directory: The system must scan a local target folder containing 2-3 isolated camera video angles (.mp4, .mov) and individual microphone audio stems (.wav).
[paragraph, list L0] Audio Extraction: Execute an automated ffmpeg background process to extract and isolate audio tracks.
[paragraph, list L0] Specification: Convert audio to 16kHz, Mono, 16-bit WAV files to optimize processing speed.
[paragraph, list L0] SMPTE Timecode Alignment: Capture and store the absolute starting timecode header from the raw files to ensure zero timecode drift during final sequence compilation.
[heading 3] Module 2: Whisper Transcription Pipeline
[paragraph, list L0] Multi-Track Text Generation: Send the primary speaker audio files to the Whisper Speech-to-Text API.
[paragraph, list L0] Word-Level Timestamping: Enforce the explicit extraction of word-level timestamps.
[paragraph, list L0] Data Schema Requirement: The pipeline must output a JSON data layout structured as follows:
[paragraph] JSON
[paragraph] {
[paragraph] "word": "Welcome",
[paragraph] "start_ms": 12500,
[paragraph] "end_ms": 12900,
[paragraph] "speaker_id": "Mic_1"
[paragraph] }
[heading 3] Module 3: Semantic RAG Narrative Filter Engine
[paragraph, list L0] Context Vector Input: Ingest the raw string payload of the "Podcast Plan" (Creative Brief).
[paragraph, list L0] Semantic Filtering Prompt: Pass the complete, chronological transcription block alongside the Podcast Plan into the LLM.
[paragraph, list L0] Model Constraint: Command the model to output only a JSON array containing highly precise timestamp blocks of conversational paths that match the target narrative arcs, filtering out tangents.
[paragraph] JSON
[paragraph] {
[paragraph] "keep_zones": [
[paragraph] {"start_ms": 10000, "end_ms": 250000, "topic": "Introduction"},
[paragraph] {"start_ms": 310000, "end_ms": 890000, "topic": "Core Discussion"}
[paragraph] ]
[paragraph] }
[heading 3] Module 4: Audio-Level Diarization & Switching Logic (Phase 1 Focus)
[paragraph] For every designated keep_zone, the Python engine must determine which camera angle to activate on a millisecond-by-millisecond layer.
[paragraph] [Calculate RMS dBFS over 100ms Window]
[paragraph] │
[paragraph] ┌─────────────────────┴─────────────────────┐
[paragraph] ▼                                           ▼
[paragraph] [Track A > Track B + 4dB?]              [Track A ≈ Track B Within 2dB]
[paragraph] │                                           │
[paragraph] ▼                                           ▼
[paragraph] Switch to Speaker A Cam                  Switch to Wide/Master Cam
[paragraph] (Hold for 1.5s Minimum)                  (Cross-Talk Event Flag)
[paragraph, list L0] Audio Filtering: Apply a 90Hz digital High-Pass Filter to eliminate background bass rumble.
[paragraph, list L0] Windowing: Slice audio arrays into 100ms intervals.
[paragraph, list L0] Loudness Calculation: Compute Root Mean Square (RMS) decibels relative to full scale (dBFS).
[paragraph, list L0] Switching Rules Engine:
[paragraph, list L1] Active Speaker: If Track_A > -45 dBFS AND (Track_A - Track_B) >= 4 dB, flag Cam_A as active.
[paragraph, list L1] Cross-Talk Event: If Track_A and Track_B are both > -45 dBFS AND abs(Track_A - Track_B) < 2 dB, flag Cam_Wide (Wide/Master Shot) as active.
[paragraph, list L1] Pacing Hold Protection: Once a camera cut decision is registered, the current camera choice must lock for a minimum of 1.5 seconds (15 windows) to avoid rapid-fire, jarring cuts.
[heading 3] Module 5: FCPXML Exporter Layer (With 0.5s Safety Handles)
[paragraph, list L0] Format Base: Generate a standard Final Cut Pro XML (v1.8 interchange schema) readable natively by Adobe Premiere Pro.
[paragraph, list L0] 0.5s Safety Handle Calculation: For every calculated edit segment array, manipulate the metadata markers programmatically before compiling the XML string:
[paragraph, list L1] xml_start_seconds = calculated_start_seconds - 0.5
[paragraph, list L1] xml_duration_seconds = calculated_duration_seconds + 1.0 (accounts for 0.5s padding at both the start and the end)
[paragraph, list L0] Lightweight Asset Mapping: Write explicit reference blocks pointing directly to local storage file roots, completely eliminating media re-linking tasks for the human editor.
[heading 3] Module 6: Micro-Moments Highlight Analyzer (Phase 2 Focus)
[paragraph, list L0] Semantic Scoring: During text transcription evaluation, configure an LLM module to detect high-emotion phrases, key consensus summaries, or self-contained semantic hooks.
[paragraph, list L0] Metadata Tagging: Extract 3 to 5 isolated "Micro-Moments" chunks per episode (target length: 30–90 seconds each).
[paragraph, list L0] XML Output Structure: Package these highlighted blocks into a secondary sub-sequence or target Project Folder Bin within the main FCPXML payload for immediate access.
